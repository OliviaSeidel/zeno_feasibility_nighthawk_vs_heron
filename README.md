# Quantum Zeno feasibility and paper analysis

This repository contains two complementary sets of notebooks for the proposed quantum Zeno experiment.

- [Sara's Nighthawk-versus-Heron feasibility notebook](zeno_feasibility_nighthawk_vs_heron_paper_version.ipynb) contains the original processor comparison. It is preserved unchanged.
- [Paper analysis notebooks and figures](paper_analysis/README.md) explain the survival curves, verify the ideal circuit, and model memory-parity loss. This includes the parity-versus-coherence plot used as Figure 3 in the current manuscript.

The paper analysis folder has its own pinned dependencies, run instructions, saved outputs, and HTML reading copies. Its hardware numbers are illustrative assumptions; read each notebook's limitations before treating them as an experimental prediction. The manuscript itself is not included here.
