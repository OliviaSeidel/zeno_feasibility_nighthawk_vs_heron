# Quantum Zeno simulations

Notebooks and figures for a quantum Zeno experiment with two measurement schedules in superposition.

The [Nighthawk and Heron feasibility notebook](zeno_feasibility_nighthawk_vs_heron_paper_version.ipynb) compares the gate counts and circuit depths needed on the two processor layouts.

The [paper analysis notebooks](paper_analysis/README.md) explain the survival curves, check the ideal circuit predictions, and estimate how memory noise reduces parity contrast. This folder also contains the plots used in the paper, including the memory storage and coherence plot in Figure 3.

Saved results are included so the notebooks can be read without running them. Setup instructions are in the paper analysis folder. The hardware estimates use illustrative parameters rather than measured device calibrations.
